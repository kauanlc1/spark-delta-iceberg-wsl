# Apache Iceberg

**Apache Iceberg** é um formato de tabela para Big Data, projetado para fornecer confiabilidade e eficiência em sistemas de processamento de dados distribuídos. Ele oferece suporte a transações ACID e integra-se com o Apache Spark, permitindo o processamento de grandes volumes de dados de forma eficiente.

## Funcionalidades

- **Gerenciamento de Tabelas em Grande Escala**: Suporta tabelas imutáveis e mutáveis.
- **Transações ACID**: Garantia de consistência e integridade.
- **Melhor Desempenho de Leitura e Escrita**: Comparado a formatos como Parquet e ORC.

Para mais detalhes sobre como utilizar o Iceberg, veja a documentação oficial: [Apache Iceberg Documentation](https://iceberg.apache.org/).
